# 實驗室的自動化點餐系統計畫

- 你是專業專案架構工程師，把這規劃的更加全面且優化

## 技術棧

- Discord bot
- TS 框架 + Node.js
- PostgreSQL
- FREE LLM API(Mistral Experiment,Gemini Flash,Groq)
- Google Cloud API
- 校園網路(基於校內伺服器IP的網站)
- Docler

## 用戶要求項目

### 功能一：餐廳菜單查詢

輸入餐廳名稱關鍵字（例：福氣來）→ 回傳該餐廳菜單清單
只能用免費 API，禁用付費服務，若無現成 API，需自行建置（爬蟲 + 自架 API）

### 功能二：揪團點餐

在論壇頻道建立新的貼文，指定用餐餐廳
Bot 自動發送該餐廳菜單
成員以文字輸入自己要點的品項
Bot 統整：全體點餐彙總清單 + 每人應付金額

### 功能三：記帳

記錄歷史消費與個人分攤結算

### 驗收要求

須正常運行一周不間斷

## 功能

可用discord帳號或google帳號登入網站
網站暫定設有兩個站(用戶介面,管理人員介面)
沒有買網域名稱，因此網站預計用校內網路位址供連上校內網路裝置登入使用

## 特色功能

需有排序，取前 10 名排序依據自行規劃並提供多種排序選擇
晚餐吃什麼抽抽樂遊戲
餐費欠錢者排序
餐點卡牌

## UI介面設計基本需求

可轉換中(繁中)/英(英式)介面，並在轉換案件加上國旗
有主題切換器可轉換深色模式（Dark Mode）與淺色模式（Light Mode）切換，主題切換器設計為有動畫的
響應式網站(在一般電腦螢幕,曲面寬螢幕,平板,手機都能有良好的體驗)

## Discord bot互動設計基本需求

斜線指令盡量用 Embed＋按鈕／下拉，避免 Modal。
等待時有 Embed 動畫過場。
停權／跨服審核／加入頻道等用 Embed 通知。


## 基礎設施

實驗室內24/7伺服器(估計性能普普，本地模型效率不佳)，在沒有買網域的情形下可以設計為亦可透過學校內網路連結網站
